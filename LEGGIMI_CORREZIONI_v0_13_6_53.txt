BUG 1 — GARAGE LAMPO ZX
Lampo ZX V4.2 utilizzava una turntable ripresa quasi dall'alto, a differenza delle altre auto.
Sostituito esclusivamente l'atlante lampo_turntable con 192 pose da GLB GARAGE V4.2: orbita di 360 gradi attorno all'asse verticale dell'auto, camera a elevazione fissa di 22 gradi.
La rotazione del garage resta automatica, senza oscillazione verticale.

BUG 2 — AUTO NON VISIBILI / PARTITA CHE NON PARTE
Il Core definiva ttrCalibratedProfile ma non lo esportava; la creazione delle auto nel motore di gara chiamava un identificatore non disponibile e produceva ReferenceError, interrompendo initRace.
Esportata ttrCalibratedProfile da TTRCore e importata esplicitamente nel motore della gara; funzionamento ripristinato in Gara Veloce ed Eliminazione (e nelle altre modalità offline).

PUBBLICAZIONE GITHUB PAGES
1. Conservare un backup dei file attualmente online, in particolare index.html.
2. Estrarre QUESTO ZIP. Non caricare lo ZIP come file singolo nel repository.
3. Nella ROOT del repository GitHub Pages sostituire index.html, manifest.webmanifest, version.txt e icone con i file di questo archivio. Conservare il file .nojekyll.
4. Eseguire commit; controllare che la nuova versione sia distribuita.
5. Visitare https://TUO-DOMINIO/version.txt e cercare v0.13.6.53. Se il browser usa cache, aggiornare la pagina e riaprire la web app.
